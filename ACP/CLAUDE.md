# 株式会社ACP - 取扱説明書(CLAUDE.md)

全体ルールはルートのCLAUDE.mdを前提とする。ここでは株式会社ACP固有の情報を扱う。

## 会社概要

- 事業:リスティング広告アフィリエイト事業、AI占い事業(いずれも稼働中)
- 位置づけ:新規事業をテスト的に行う会社。収益性が見込めた事業は、別の売却可能な新会社を設立してそちらに移していく方針。
- 体制:伊藤・上松野の2名のみ(各50%)

## フォルダ構成と役割

- listing-ads/:リスティング広告アフィリエイト事業
  - todos.md / logs.md / ideas.md / kpi.md
- ai-uranai/:AI占い事業
  - todos.md / logs.md / ideas.md / kpi.md
- ideas.md(ACP直下):特定の事業(listing-ads/ai-uranai等)に限らない、ACP全体に関わるアイデア・構想を記録する
- 新規事業が立ち上がった場合は、都度この下にフォルダを追加する

## 標準目標(常に意識すること)

- 各事業について、ルートCLAUDE.mdの「成長判断の3軸(解約低下・顧客拡大・利益拡大)」で評価する。
- 「売却前提の判断基準(属人化の最小化・仕組み化・違法性)」は、ACPでは特に新規事業を独立会社として切り出せる状態にできているかという観点で重視する。
- 事業ごとの収益性を継続的に見極め、独立会社化(新会社設立)の判断材料をkpi.mdの推移から提示できるようにする。

## 記録ルール

- リスティング広告事業の会話・タスクは[ACP/listing-ads]として記録
- AI占い事業の会話・タスクは[ACP/ai-uranai]として記録
- 新規事業が発生した場合、伊藤に事業名を確認したうえで新しいタグ・フォルダを作成する
