# スポットmovie メール振り分けルール(mail-triage.md)

対象アカウント:contact@spot-movie.com

## 実行頻度・実行時刻

毎日午前6時と午後15時の1日2回、このファイルのルールに沿ってcontact@spot-movie.comの受信メールを確認する。

## 振り分けルール

以下のいずれかに該当する場合は「要返信」として扱い、それ以外は返信不要として扱う(受信メールの約9割は返信不要の想定)。

- 企業(法人)からのメール(M&A仲介会社・買収候補企業に限らず、業務委託先など企業とのやり取り全般を含む) → 担当:伊藤(ラベル「要返信:伊藤」)
- 上記以外で返信が必要と判断されるもの(主に顧客である政治家とのやり取り) → 担当:上松野(ラベル「要返信:上松野」)
- オンライン説明の予約が入った場合(Google Meetの予約確認は自動送信で完結するため)は基本的に返信不要。ラベルを付けず、下書きも作成しない。ただし、稀に個別の返信が必要と判断した場合は、運営事務局名義(上松野担当と同じ書式)で対応する
- 返信不要と判断したものにはラベルを付けない(ラベルが付いている=対応が必要、と一目でわかる状態を保つため)

この振り分けルール(誰が何を担当するか)は運用しながら変更されることがある。伊藤から変更の指示があれば、このセクションを更新すること。

## 下書き作成ルール

要返信と判定したメールには、以下を満たす返信下書きを、該当メールのスレッド内に作成する。

- 相手が企業(法人)か、顧客である政治家かによって、下記「書き出しの挨拶」を使い分ける
- 下記の署名テンプレートを本文最下部に挿入する
- なぜ返信が必要と判断したか、簡潔な理由をメモとして添える(下書き本文とは別に分かる形で)
- カレンダー通知など、返信元メールのヘッダー情報が不十分なメールに返信下書きを作成すると、Gmail側で元スレッドとは別の新規スレッド扱いになることがある。その場合、ラベルは元メールのスレッドだけでなく、下書きが実際に格納されているスレッド側にも付け直すこと(`list_drafts`で下書きの`threadId`を確認する)

## 書き出しの挨拶・署名(担当者による使い分け)

冒頭の挨拶と末尾の署名は、返信担当が伊藤か上松野かで以下のように使い分けること。上松野が担当する場合、上松野の個人名はメールに一切出さない(冒頭・署名とも「運営事務局」表記にする)。

宛名と挨拶文の間は空行を2行あけ、挨拶文は「お世話になっております。」の後で改行して2行にすること。結びの一文と署名の間も空行を2行あけること。

### 伊藤担当の場合(企業・M&A仲介会社向け)

冒頭:
```
○○様


お世話になっております。
株式会社EIMの伊藤でございます。
```

署名:
```
政治家専用 ショート動画制作クラウド | スポットmovie 伊藤俊
contact@spot-movie.com
運営元：株式会社EIM
宮城県仙台市宮城野区福室2-8-17福室マンション314号
```

### 上松野担当の場合(顧客である政治家向け)

冒頭:
```

お世話になっております。
政治家専用ショート動画制作クラウド スポットmovie運営事務局でございます。
```

署名:
```
政治家専用 ショート動画制作クラウド | スポットmovie 運営事務局
contact@spot-movie.com

```

## 下書きの確認方法

左サイドバーのラベルをクリックしても下書きが表示されない場合がある(上記「下書き作成ルール」の通り、下書きが別スレッド扱いになっているケースなど)。確実に確認したい場合は、Gmail検索窓で以下のように検索する。

- `in:drafts label:"要返信:伊藤"`
- `in:drafts label:"要返信:上松野"`

## 誤判定への対応

- ラベルが付いているが実際は返信不要と判断した場合、そのメールのラベルを外すだけでよい(返信せず放置してよい)
- 同様の誤判定が繰り返される場合は、伊藤または上松野からClaude Codeにその旨を伝え、このファイルの振り分けルールを更新する
