# スポットmovie メール振り分けルール(mail-triage.md)

対象アカウント:contact@spot-movie.com

## 実行頻度・実行時刻

毎日6時・13時・18時の1日3回、このファイルのルールに沿ってcontact@spot-movie.comの受信メールを確認する。

## 確認対象の範囲

毎回、直近24時間以内に受信したメール(`newer_than:1d`)を確認対象とする。過去の全履歴を毎回遡ることはしない。6時・13時・18時の実行間隔より長い範囲を見ることで、万が一どちらかの回の実行が漏れても次回でカバーできるようにしている。

### 注意:長期スレッドの見落とし対策

`search_threads`は、1スレッドあたりのメッセージ一覧を古い方から数件に切り詰めて返すことがある。そのため、M&A仲介とのやり取りなど何十通も続く長期スレッドでは、`newer_than:1d`条件でスレッド自体はヒットしても、一覧に表示されるメッセージが実際には古いものだけで、当日の新着メッセージが一覧に反映されないことがある(実際に発生した見落とし事例あり)。

対策として、`search_threads`の結果で、あるスレッドの表示メッセージがすべて確認対象期間より古い場合は「新着なし」と即断せず、そのスレッドIDを`get_thread`で個別に取得し、実際の最新メッセージを確認すること。特に、過去にM&A仲介会社等とのやり取りで既に何度もラベル付け・下書き作成を行ったことがある「動きの多いスレッド」は、`search_threads`の一覧だけで判断せず`get_thread`で直接確認することを基本とする。

## 振り分けルール

ラベル「要返信:伊藤」「要返信:上松野」は、メール返信が必要な場合だけでなく、返信は不要でも内容の確認・対応が必要な場合にも付ける(=「対応が必要」の目印として運用する)。以下のいずれかに該当する場合はラベルを付け、それ以外は付けない(受信メールの約9割はラベル不要の想定)。

- 企業(法人)からのメール(M&A仲介会社・買収候補企業に限らず、業務委託先など企業とのやり取り全般を含む) → 担当:伊藤(ラベル「要返信:伊藤」)、返信下書きを作成する
- 請求書・料金明細など、返信は不要だが内容確認が必要な通知メール(例:ラクスWeb料金明細サービス等) → 担当:伊藤(ラベル「要返信:伊藤」)、返信下書きは作成しない(確認のみでよいため)
- 上記以外で返信が必要と判断されるもの(主に顧客である政治家とのやり取り) → 担当:上松野(ラベル「要返信:上松野」)、返信下書きを作成する
- オンライン説明の予約が入った場合(Google Meetの予約確認は自動送信で完結するため)は基本的に返信不要。ラベルを付けず、下書きも作成しない。ただし、稀に個別の返信が必要と判断した場合は、運営事務局名義(上松野担当と同じ書式)で対応する
- 対応不要と判断したものにはラベルを付けない

この振り分けルール(誰が何を担当するか)は運用しながら変更されることがある。伊藤から変更の指示があれば、このセクションを更新すること。

## 下書き作成ルール

要返信と判定したメールには、以下を満たす返信下書きを、該当メールのスレッド内に作成する。

- 相手が企業(法人)か、顧客である政治家かによって、下記「書き出しの挨拶」を使い分ける
- 下記の署名テンプレートを本文最下部に挿入する
- なぜ返信が必要と判断したか、簡潔な理由をメモとして添える(下書き本文とは別に分かる形で)
- 下書きを`create_draft`または`update_draft`で作成・編集するたびに、Gmail側でその下書きが別の新規スレッド扱いになることがある(カレンダー通知など元メールのヘッダー情報が不十分な場合に特に起きやすいが、通常の返信でも編集のたびに起こりうる)。そのため、下書きを新規作成した直後だけでなく、**既存の下書きを編集(update_draft)した直後も必ず**`list_drafts`で該当下書きの現在の`threadId`を再確認し、ラベルをその時点の正しいスレッドに付け直すこと。ラベルを付けたスレッドと下書きが実際に入っているスレッドが一致しているか、都度チェックする

## 書き出しの挨拶・署名(担当者による使い分け)

冒頭の挨拶と末尾の署名は、返信担当が伊藤か上松野かで以下のように使い分けること。上松野が担当する場合、上松野の個人名はメールに一切出さない(冒頭・署名とも「運営事務局」表記にする)。

宛名と挨拶文の間は空行を2行あけ、挨拶文は「お世話になっております。」の後で改行して2行にすること。結びの一文と署名の間も空行を2行あけること。

### 伊藤担当の場合(企業・M&A仲介会社向け)

冒頭:
```
○○様


お世話になっております。
株式会社EIMの伊藤でございます。
```

署名:
```
政治家専用 ショート動画制作クラウド | スポットmovie 伊藤俊
contact@spot-movie.com
運営元：株式会社EIM
宮城県仙台市宮城野区福室2-8-17福室マンション314号
```

### 上松野担当の場合(顧客である政治家向け)

```

お世話になっております。
政治家専用ショート動画制作クラウド スポットmovie運営事務局でございます。
```

署名:

## 下書きの確認方法

左サイドバーのラベルをクリックしても下書きが表示されない場合がある(上記「下書き作成ルール」の通り、下書きが別スレッド扱いになっているケースなど)。確実に確認したい場合は、Gmail検索窓で以下のように検索する。

- `in:drafts label:"要返信:伊藤"`
- `in:drafts label:"要返信:上松野"`

## 誤判定への対応

- ラベルが付いているが実際は対応不要と判断した場合、そのメールのラベルを外すだけでよい
- 同様の誤判定が繰り返される場合は、伊藤または上松野からClaude Codeにその旨を伝え、このファイルの振り分けルールを更新する
